**VPN Bot** — это стабильное, готовое к коммерческому использованию (*production-ready*) решение для автоматической продажи безопасного **VLESS + Reality** доступа. 

Бот спроектирован по принципу децентрализации: он не управляет вашим сервером напрямую, а безопасно взаимодействует с ним через **HTTP API панели [3x-ui](https://github.com)**. Все операции по созданию, продлению и контролю лимитов пользователей полностью автоматизированы.

---

## 🚀 Ключевые возможности & Фичи

- **⚡ Масштабируемая архитектура**: Мгновенное добавление новых локаций (стран) через БД. Умная балансировка нагрузки между серверами по количеству активных ключей.
- **💳 Гибкие платежные шлюзы**: Интеграция с **ЮKassa** (банковские карты), **Telegram Stars** (внутриигровая валюта XTR), встроенный баланс пользователей и очередь ручной модерации оплат.
- **🔄 Асинхронный движок**: Реализован на `aiogram 3.x`, поддерживает переключение между `Long Polling` и производительными `Webhooks` (через aiohttp).
- **🛠️ Мощная Админ-панель (`/admin`)**: Полная аналитика бизнеса (статистика выручки, MRR, конверсия триал ➔ покупка), управление промокодами, встроенная система тикетов техподдержки и кастомные сегментированные рассылки.
- **🔒 Безопасность уровня Enterprise**: Секретные ключи панелей шифруются алгоритмом **Fernet** прямо в БД. Чувствительные данные (пароли, cookies, токены) автоматически вырезаются из логов. Защита от дублей платежей через блокировку строк `FOR UPDATE`.

## 🛠️ Быстрый старт

### Локальная разработка (Dev)

1. Клонируйте репозиторий и настройте переменные окружения:
   ```bash
   cp .env.example .env  # Укажите ваш BOT_TOKEN, SECRET_KEY и доступы к 3x-ui
   ```
2. Поднимите виртуальное окружение и установите зависимости:
   ```bash
   python3 -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt -r requirements-dev.txt
   ```
3. Сгенерируйте секретный ключ для шифрования данных:
   ```bash
   SECRET_KEY=$(python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())")
   ```
4. Примените миграции, заполните тарифную сетку и запустите бота:
   ```bash
   make upgrade  # Запуск alembic-миграций
   make seed     # Накатить базовые тарифы и первый сервер из .env
   make run      # Запуск бота (Long Polling)
   ```

### Развертывание в Docker (Prod)

```bash
cp .env.example .env && nano .env
docker compose up -d --build
docker compose exec bot alembic upgrade head
docker compose exec bot python -m app.cli seed_server
docker compose exec bot python -m app.cli seed_plans
```

## ⚙️ Встроенное расписание (Background Jobs)

Бот содержит изолированный планировщик задач, контролирующий состояние инфраструктуры:

* `sync_traffic` (Каждые 15 мин) — Синхронизация объема трафика клиентов с БД.
* `expire_check` (Каждые 10 мин) — Отключение просроченных клиентов в панели 3x-ui.
* `notify_expiring` (Каждый 1 час) — Мягкие уведомления пользователей об окончании подписки за 3 дня / 1 день / 3 часа.
* `reconcile_payments` (Каждые 5 мин) — Валидация зависших статусов платежей через API ЮKassa.
* `retry_provisioning` (Каждые 2 мин) — Повторная автоматическая выдача ключей в случае сбоев сети (до 3 попыток).

## 📈 Масштабирование и Production-оптимизация

- **Мультисерверность**: Для добавления новой геолокации достаточно выполнить `INSERT` в таблицу `servers`. Меню выбора стран адаптируется автоматически.
- **Отказоустойчивость**: Процесс планировщика задач (`scheduler`) легко выносится в отдельный изолированный Docker-контейнер для снижения нагрузки на основной процесс бота.
- **Высокие нагрузки**: Бот подготовлен к горизонтальному скейлингу веб-слоя за `Nginx` (при использовании вебхуков) и интеграции `Redis` в качестве хранилища состояний FSM.
