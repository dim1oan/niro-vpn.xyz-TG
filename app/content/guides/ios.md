# Подключение на iOS

## Установка клиента

Скачайте один из клиентов:

- [Streisand](https://apps.apple.com/app/streisand/id637855861) — рекомендуем
- [v2Box](https://apps.apple.com/app/v2box/id6446814690)
- [Happ](https://apps.apple.com/app/happ/id6504287215)

## Подключение

1. Откройте сообщение с ключом в боте и нажмите на ссылку `vless://...` — она скопируется.
2. Откройте клиент → **+** → *Импорт из буфера обмена*.
3. Выберите добавленный сервер и нажмите кнопку подключения (большая круглая).
4. Разрешите создание VPN-профиля при первом подключении.

## Проверка

Откройте [2ip.ru](https://2ip.ru) — страна должна смениться на страну вашего сервера.

## Если не работает

- Переключите протокол туннеля: Настройки → TUN/Proxy.
- Переустановите профиль (удалите сервер и импортируйте заново).
- Напишите нам через 🆘 Поддержка.
