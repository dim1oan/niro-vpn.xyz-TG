# Подключение на Android

## Установка клиента

Скачайте клиент:

- [v2rayNG](https://play.google.com/store/apps/details?id=com.v2ray.ang) — рекомендуем
- [Happ](https://play.google.com/store/apps/details?id=com.happproxy)

## Подключение

1. Скопируйте ссылку `vless://...` из бота (тап по ней).
2. v2rayNG → **+** → *Импорт конфига из буфера обмена*.
3. Выберите профиль и нажмите кнопку ▶ внизу.
4. Подтвердите запрос VPN-соединения.

## Проверка

Откройте [2ip.ru](https://2ip.ru) — страна должна смениться.

## Если не работает

- В v2rayNG: Настройки → Режим маршрутизации → «Обход материка» или «Глобально».
- Обновите ядро: Настройки → Проверить обновление Xray.
- Не помогло? 🆘 Поддержка.
