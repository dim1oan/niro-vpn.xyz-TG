# Подключение на Windows

## Установка клиента

Скачайте один из клиентов:

- [Hiddify](https://github.com/hiddify/hiddify-app/releases/latest) — рекомендуем
- [NekoRay / NekoBox](https://github.com/MatsuriDayo/nekoray/releases)
- [v2rayN](https://github.com/2dust/v2rayN/releases)

## Подключение (Hiddify)

1. Скопируйте ссылку `vless://...` из бота.
2. Hiddify → **+** → *Добавить из буфера обмена*.
3. Нажмите большую кнопку подключения.

## Подключение (v2rayN)

1. Скопируйте ссылку, затем: Серверы → Импорт из буфера обмена (Ctrl+V).
2. Правый клик по иконке в трее → Режим системного прокси → Автонастройка.

## Если не работает

- Проверьте, что включён системный прокси / режим TUN.
- Смените клиент (Hiddify ↔ NekoRay).
- Временно отключите антивирус/файрвол.
- 🆘 Поддержка всегда поможет.
